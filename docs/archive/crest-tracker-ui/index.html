The screenshots capture the implemented interface with disposable test data. The offline demo is an earlier proposal with temporary fixtures, no backend, audio or persistence; its controls differ from the final experiment. It remains unchanged for reference.

Visual ingredients

Dark panels, square borders, dense monospace rows, large workspace titles, cyan focus, pink values and green status. Azeret Mono is used when installed; system monospace fonts provide the fallback.
