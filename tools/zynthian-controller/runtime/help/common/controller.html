Zynthian controller interface

This HTML interface uses Zynthian's engines, routing, parameters and snapshot files. Choose a view in the left navigation. More screens contains Chain Manager, Add Chain, Chain Control, Banks / Presets, ZS3, Tempo, Audio Player, MIDI Player / Recorder, Audio Levels, MIDI Input, MIDI Output and Administration.

Selecting and editing

Click an item to activate it. Options opens the selected item's native secondary action. Parameter rows provide minus, plus and direct numeric entry. Toggle parameters change when selected. Screen options opens the current view's menu. Back returns through Zynthian's screen history. Confirmations have separate Cancel and Confirm buttons.

Chains and sounds

Add Chain creates instruments, audio effects, MIDI effects and other chain types supported by the installed backend. Select an engine, MIDI channel, bank and preset. Chain Control lists processors, parameter pages and routing tabs. Each processor has an Options button; each parameter has its native control options, including MIDI learning, automation CC assignment, value range and X/Y assignment when available.

MIDI and audio routing

Use a chain's MIDI input to change its MIDI channel, allowed CCs, key range and transposition. Global MIDI Input and MIDI Output list devices and services. Audio input and Audio output select the chain's connections. Mixer exposes native level, balance, mute, solo and other mixer parameters supplied by the backend.

Sequencing

Sequencer opens the clip and phrase launcher. Select a clip, then use Edit in its context menu. In the piano roll, select a cell and use Note to add or remove a note. The context menu provides note parameters, block operations, undo/redo, pattern settings and CC editing. The CC view edits the selected controller's events. These operations use Zynthian's native sequencer.

Playback, recording and sessions

Enable audio in the header to hear output in the browser. The main menu contains audio and MIDI recording controls. Audio Player and MIDI Player select recordings and files. Save your work through Snapshots; use ZS3 for subsnapshots. Presets, snapshots and recordings remain in the host data directory.

Controller navigation

D-pad or left stick moves selection; A selects; B goes back; Y invokes options. Start opens Main Menu. In editors, X plays, left-stick click opens the context menu, and the right stick adjusts note values. Keyboard arrows, Enter and Escape perform basic navigation. Controller layout remains provisional.

Host capabilities

Administration reflects the running Zynthian backend. Hardware-dependent controls appear when the backend supplies them. Touchscreen calibration requires the physical display. Browser operation does not establish physical MIDI, Pi or Steam Deck compatibility.
